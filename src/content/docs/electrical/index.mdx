## 🛠️ How to Add More Electrical Documents
1. Save your PDF into `public/study-files/electrical/your-document.pdf`.
2. Duplicate `src/content/docs/_templates/study-reader.mdx` into `src/content/docs/electrical/`.
3. Set the PDF path in the `iframe` tag and commit!
