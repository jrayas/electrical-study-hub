## 💡 How to Add More Textbooks or Papers (Zero MDX)

You do **not** need to create any `.mdx` or code files to add new study material:

1. Drop your `.pdf` file directly into your local folder:
   ```
   public/study-files/electrical/your-textbook.pdf
   ```
2. Commit and push:
   ```bash
   git add . && git commit -m "add: new electrical book" && git push
   ```
3. The bookshelf above **automatically discovers** the new file, formats its title, calculates its file size, and generates the full-screen reader link!
