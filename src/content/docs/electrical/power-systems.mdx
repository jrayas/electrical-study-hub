## 📝 Companion Notes & Formulas

<Tabs>
  <TabItem label="⚡ Balanced Three-Phase Systems">
    ### Three-Phase Power Relationships

    In a balanced three-phase system with line voltage `V_L` and line current `I_L`:

    **Wye (Y) Connection:**
    ```text
    V_L = sqrt(3) · V_ph ∠ 30°
    I_L = I_ph
    ```

    **Delta (Δ) Connection:**
    ```text
    V_L = V_ph
    I_L = sqrt(3) · I_ph ∠ -30°
    ```

    **Total Three-Phase Complex Power:**
    ```text
    S_3φ = sqrt(3) · V_L · I_L* = 3 · V_ph · I_ph* = P_3φ + jQ_3φ
    P_3φ = sqrt(3) · V_L · I_L · cos(θ) [Watts]
    ```
  </TabItem>

  <TabItem label="🌐 Transmission Line Modeling">
    ### Medium-Length Line (Pi-Model)

    The ABCD transmission matrix relates sending-end and receiving-end parameters:
    ```text
    [V_S]   [A  B] [V_R]
    [I_S] = [C  D] [I_R]
    ```
    Where `A · D - B · C = 1` for a reciprocal network.
  </TabItem>
</Tabs>
