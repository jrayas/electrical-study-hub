# Project Rules & Permissions

## Autonomous Development & Execution Permissions
- Full autonomy is granted to create, edit, and manage all project files, configuration, content, templates, and scripts.
- Commands required to build, test, and maintain this Astro Starlight + PDF.js + Hypothesis study hub may proceed without restriction.
- Auto-approve read, write, and command execution for this workspace to complete the study hub setup.

## Development Commands
When running the development server:
```
npm run dev
```
or background mode:
```
astro dev --background
```
Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Documentation & Best Practices
- Framework: [Astro Starlight](https://starlight.astro.build/)
- PDF Engine: [Mozilla PDF.js](https://mozilla.github.io/pdf.js/)
- Annotation: [Hypothesis](https://hypothes.is/)
